# DEBE Auto — Decide Better

O **DEBE** é uma ferramenta gratuita em beta para ajudar compradores de carros usados em Portugal a avaliar anúncios antes da compra.

**Teste o DEBE:** https://debe-auto.onrender.com/

O utilizador cola o link de um anúncio de um marketplace automóvel e o DEBE procura reunir num único relatório:

- score preliminar do anúncio;
- pontos fortes e contexto favorável;
- problemas reportados para o modelo e motorização;
- verificações recomendadas antes da compra;
- negócios comparáveis disponíveis no mercado.

O objetivo desta beta é validar se existe procura real por uma ferramenta independente de apoio à decisão na compra de automóveis usados.

## Nota

O DEBE é uma ferramenta de apoio à decisão. Não substitui inspeção mecânica, diagnóstico eletrónico, validação documental ou aconselhamento profissional.
